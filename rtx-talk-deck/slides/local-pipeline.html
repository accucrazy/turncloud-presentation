工作流圖解：商品照 進，成片與故事 出

不是單純文字生圖 ── 以商品圖與品牌風格為約束，每一站的輸出都是下一站的輸入，全程不離開這台機器。

STEP 1
擷取商品素材
商品頁單品照、假人照、官網實穿照與風格參考圖。
→
STEP 2
生成模特兒實穿
reference edit / 低重繪保衣服，套用品牌人設與台灣網拍語感。
→
STEP 3
實穿圖 → 影片
image-to-video，靜態實穿變成會動的商品短片。
→
STEP 4
狗血故事腳本
地端 LLM 依商品與人設生成戲劇化敘事，直接配上短影音。
→
STEP 5
上架 / 投放
成圖、成片、腳本齊備，接回上一章的 Agent 產線發佈。

引擎 · ComfyUI

node-based 工作流，模型、參數、流程全部版本化，可複製、可調校、可交接。

算力 · RTX 5090

32GB VRAM + Blackwell 世代算力，圖生圖、圖生影、本地 LLM 同一張卡全包。

模型 · 可替換

Flux2 Klein / NemoClaw × Nemotron nano ── 模型演進時換節點不換流程。
