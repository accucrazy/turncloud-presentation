BANANA SPLIT · CLI

產線就是一行指令，套路就是 plugin

接下來流行的是 CLI：裝上就能跑、plugin 隨插隨用。你的素材設計套路是一個 plugin， Cody、Claude Code、Cursor 這些 agent 也從同一條 CLI 串進來 —— 人人都能把自己的套路放上來。

ECOSYSTEM · 台灣就有的六種生意

一把 key、一條 CLI，就是一間公司

這六間不是想像的科幻公司，是台灣現在就存在的團隊：小編工作室、電商代營運、 廣告代理商、KOL 電商、獨立開發者。他們不用懂 AI，把自己的套路裝上這條 CLI， 原本的生意直接變快、變便宜 —— 而每一次執行，都記在我們的帳上。

不管哪一間公司，跑一次都留下同一張單據 這就是敢把生意掛上來的原因 · 花多少、誰跑的、過沒過驗收，一張看完
