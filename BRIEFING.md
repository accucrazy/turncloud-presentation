> **Runtime lets AI run space. AI OS lets the enterprise manage AI. AI Agents are where business value actually happens.**

### 3.3 The "what's broken today" framing

Most enterprises are already using AI — for copy, for images, for analytics, for support, for reports. The problem isn't that they don't have AI. The problem is:

- The AIs are **point tools**, not a system.
- Each department uses its own.
- Data isn't joined.
- Agents don't collaborate.
- Results can't be governed.
- And experience never sediments into an enterprise asset.

> **企業缺的不是更多 AI 工具，而是一套能讓 AI 被管理、被協作、被擴充的作業系統。**

### 3.4 The product answer: Enterprise AI OS

Enterprise AI OS is the layer that unifies, in one place:

- **Data** — the company's data and lineage
- **Memory** — the company's institutional memory + per‑user memory
- **Workflow** — declarative business workflows
- **Agents** — registered AI workers with KPIs
- **Permission** — RBAC, tool policy, audit
- **Governance** — model lifecycle, ESG, compliance
- **Dashboard** — what happened, what AI did, what changed
- **Decision** — human‑in‑the‑loop where it matters

It is **not** a chatbot, it is **not** a Copilot. It is the **OS that lets a company employ a workforce of AI Agents.**

## 4. The technology stack (depth for Q&A / press)

### 4.1 OpenClaw — the framework underneath every Agent

- **Agent Registry** — each agent registered with its own system prompt, skills whitelist, tools whitelist.
- **ReAct Loop** — Thought → Action → Observation, with native function calling (no fragile text parsing).
- **Plugin System** — Lifecycle hooks (`beforeRun` / `afterRun` / `onError`) + tool hooks. Extension is unbounded.
- **Session Scoping** — session isolation, error recovery, typing indicator, all OpenClaw‑native.
- **Tool Policy** — per‑user, per‑tool fine‑grained permission + audit logging.
- **Open source @** `claw3d.ai`
- Jensen Huang reference point (Morgan Stanley TMT 2026): OpenClaw cited as "3 weeks beyond what Linux did in 30 years." Use this as social proof.

### 4.2 User‑Level Memory (the moat)

Three layers, per user:

1. **Conversation** — vector search (cosine) + BM25 hybrid retrieval; 50K LRU embedding cache.
2. **LTM (Long‑Term Memory)** — Auto‑Recall + Auto‑Capture, gated by LLM confirmation before write.
3. **Profile** — structured fields (name, company, role, preferences) + free‑form communication style.

> 「不只記住你說了什麼，更記住你是誰、你在乎什麼。」

**Why this matters commercially:** memory is the moat. Per‑seat memory = per‑seat lock‑in = compounding revenue.

### 4.3 Pandora — the most mature Agent

- 15 skills · 46 tools · 3 memory layers
- Channels: Web Chat, Google Chat, **LINE**, Custom
- Providers: Gemini 3 (primary), OpenAI GPT, custom LLMs
- Memory: PostgreSQL + pgvector (primary), Firestore, SQLite
- Tools include: Google Search, URL Context, Web Fetch, BigQuery, Threads scraping, sentiment analysis, Python sandbox, Files API for large multimodal uploads.
- Status: **MVP LIVE**, serving real brands.

### 4.4 The data backbone — MDP + BigQuery + Semantic Layer

This is the *Data is Gold* story. It pairs perfectly with the Chairman's Runtime story because Runtime needs data to operate on.

```
L5  User Interface          per‑seat memory · NLQ · dashboard
L4  AI Agent Layer          OpenClaw (Pandora / Moana / Banana / SQL / Stacey)
L3  Semantic Layer          business language ↔ SQL
L2  MDP (BigQuery)          AI‑ready data warehouse, ETL/CDC/dbt/Airflow
L1  Source systems          TPOS · TCRM · TCMS · OLink · iFore · TShop · social
```

Key product punchline: **MDP is what makes "data" into "data that can talk back."**

### 4.5 A2A + MCP + WebMCP — the open ecosystem

- **A2A Protocol** — Agent‑to‑Agent. Pandora ↔ AIOps ↔ TCRM. Not one super‑agent — *a network of specialists, the way a real org actually works.*
- **MCP (Model Context Protocol)** — how agents plug into tools and context.
- **WebMCP** — next‑gen MCP where the agent doesn't just call APIs, it can browse the web *as a tool*. Every website becomes a potential AI tool.
- This is also the **doorway for third‑party developers** to join the AI OS — TPC is being explicitly framed as "the first third‑party node" to prove the ecosystem is open. Encourages a developer flywheel.

### 4.6 Enterprise‑grade deployment (OpenClaw Enterprise)

- **GCP VM + OpenClaw + User‑Level Memory** = turnkey enterprise deployment.
- Runs **inside the customer's GCP project**, not as SaaS multi‑tenant.
- **Data never leaves the customer environment.** This is the answer to "is my data safe?"
- Pairs with next‑gen video models (native generation/analysis/editing) — from text Agent to full‑media Agent.

## 13. Glossary (one‑liners to keep terms tight)

- **Runtime** — the environment in which a program (or AI) actually executes. TurnCloud is building this for *physical space*.
- **AI OS** — the operating system built on top of Runtime. Manages data, memory, workflow, agents, governance.
- **AI Agent** — a specialised AI worker with autonomous planning, tool use, persistent execution, and self‑correction.
- **OpenClaw** — TPC's open Agent framework (`claw3d.ai`). Modular, pluggable, ReAct‑native.
- **MDP** — Multi Data Platform. AI‑ready data layer across retail / F&B / mall / hospitality.
- **A2A** — Agent‑to‑Agent protocol. Open standard for cross‑agent collaboration.
- **MCP / WebMCP** — Model Context Protocol; WebMCP extends it so agents can browse the web *as* a tool.
- **AAAS** — Agent‑as‑a‑Service. SaaS sells tools; AAAS sells outcomes.
- **Token + Seats** — TPC's dual billing engine. Usage + per‑user memory.
- **The Pocket Company (TPC)** — AccuCrazy's branded AI Agent product line; positioned as the first third‑party node on TurnCloud's AI OS.
- **T Coeus AI OS** — TurnCloud's commercial AI OS product brand.
